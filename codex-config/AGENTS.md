- Markdown の二重アスタリスク（`**`）による強調を使用しない
- Python を一切使用しない。実装、ビルド、テスト、ローカル配信、デプロイ、補助スクリプトにも Python を使わない
- `justfile` のレシピ、コマンド例、プロジェクトに同梱されるシェルスクリプトなどは Nushell で書く
- クソみたいなテストを書かないこと。特に他の実装箇所や外部のライブラリやAPIで保証されている不変条件についてテストを書かないこと
- プロンプトで明示的に指定されたTODOコメントなどを除き、一切コメントを書かないこと。コード上に表現されない非自明な制約など、書くべきである場合は提案する

## elm
- 1回しか使わない `let` の束縛やhelper関数は使用箇所にinlineする。
- cssを変数定義して共有しない。
- cssでの色指定には基本的にPalette.elmを使う。borderや文字の色のみを指定する場合はColor.elmを使う。
    - 近い色がない場合はPalette.elmに新規作成する。
- レコードのフィールド書き込みはRecordSetterのセッターを使う。新規定義したレコードについてもsetemで自動で生成される。
    - RecordSetterはexpose(..)してよい
- 引数順は動的な状態ほど後に置くこと
- elm-cssを使用すること
