- ユーザー向けの応答で、Markdown の二重アスタリスク（`**`）による強調を使用しない
- Python を一切使用しない。実装、ビルド、テスト、ローカル配信、デプロイ、補助スクリプトにも Python を使わない
- Bash は使わない。シェルスクリプト、`justfile` のレシピ、コマンド例などは Nushell で書く
- プロンプトで明示的に指定されたTODOコメントなどを除き、一切コメントを書かないこと。

## elm
- 1回しか使わない `let` の束縛や helper 関数は、使用箇所に inline する。
- cssを変数定義して共有しない。
- cssでの色指定にはpaletteを使う。
    - 近い色がない場合はPalette.elmに新規作成する。
- レコードのフィールド書き込みはRecordSetterのセッターを使う。新規定義したレコードについてもsetemで自動で生成される。
